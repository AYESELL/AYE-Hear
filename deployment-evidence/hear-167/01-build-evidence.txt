INSTALLER OVERWRITE BEHAVIOUR ANALYSIS
===========================================================================
All [Files] entries in build\installer\ayehear-installer.iss use:
  Flags: ignoreversion

Inno Setup 6 behaviour with ignoreversion:
  → Files are ALWAYS overwritten unconditionally, regardless of existing version.
  → Applies to ALL file types: .exe, .dll, .yaml, .sql, .txt, .pyd, .so
  → config\default.yaml:  WILL be overwritten on upgrade  ✅
  → ayehear\storage\migrations\*.sql: WILL be overwritten on upgrade  ✅
  → No skipping of existing files at any point  ✅

FIX INCLUDED (HEAR-167):
  Old: Excludes: "_internal\models\*"
  New: Excludes: "_internal\models"
  Reason: In Inno Setup 6 the pattern _internal\models\* only matches direct
  children of that directory; deep subdirs (e.g. _internal\models\whisper\TheChola\...)
  were NOT excluded and would have been compressed twice (once via the nocompression
  entry, once via the catch-all entry). Using the bare directory name correctly
  excludes the entire subtree from the compressed pass.
